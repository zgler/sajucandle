# 사주캔들 앱 피봇 설계 스펙

> 작성일: 2026-05-13
> 상태: Draft → 리뷰 대기

## 1. 배경 & 문제

### 현재 상태
- Phase 4 완료. 백엔드 사주 엔진 + 퀀트 시그널 엔진 구현 완료.
- 프론트엔드 없음. API + 이메일/텔레그램 렌더링만 존재.
- 월 1회 리밸런싱 시그널 (미국 대형주 30개 중 상위 5개).

### 핵심 문제
**앱을 써야 할 동기가 없다.**

- 사주 × 투자 상관관계는 백테스트 결과 무의미 (Null Test FAIL, z = −7.46).
- 사주를 가중치/필터로 사용해도 순수 퀀트 대비 개선 없음.
- 월 1회 시그널만으로는 반복 사용 동기 부족.
- 범용 운세앱(점신, 네이버)과도, 퀀트 시그널앱(증권사)과도 차별점이 불명확.

### 결론
사주의 역할을 "투자 성과 도구"에서 **"투자자를 위한 일상 콘텐츠"**로 전환한다.

## 2. 제품 정의

### 한줄 정의
**투자자를 위한 사주 앱. 내 사주로 보는 투자 체질·매매 기운 + 퀀트 시그널.**

### 타겟 사용자
- **40~50대**, 사주/명리에 관심 있고 투자(주식/코인)도 하는 층.
- 구매력 있음. 카카오톡이 주 소통 채널.
- 명리 용어(일주, 오행, 천간지지)에 기본 이해 있음.

### 포지셔닝
```
일반 운세앱 ←────── 사주캔들 ──────→ 퀀트 시그널앱
(점신, 네이버)    투자 특화 사주     (증권사, 로보어드바이저)
                 여기만의 영역
```

범용 운세앱과 경쟁하지 않는다. 퀀트 시그널앱과도 경쟁하지 않는다.
**"투자하는 사주 팬"이라는 니치를 독점한다.**

### 일반 운세앱과의 차이

| 일반 사주앱 | 사주캔들 |
|---|---|
| 재물운 / 건강운 / 대인운 | **매매운 / 판단운 / 리스크운** |
| "오늘 금전 조심" | **"오늘은 충동 매수 조심, 관망이 이로운 날"** |
| 올해 총운 | **"당신의 사주는 장기투자 체질 — 단타에 약한 명식"** |
| 궁합 | **종목과의 오행 궁합** (재미 요소, 미래 검토) |

### 핵심 원칙
1. **사주가 수익률을 올려준다고 주장하지 않는다.** 엔터테인먼트 + 자기이해 도구.
2. **퀀트 시그널은 사주와 독립.** 순수 퀀트 기반임을 명시.
3. **매일 앱을 열 이유를 만든다.** 일진 기반 콘텐츠가 매일 바뀜.

## 3. 화면 구성

### 3.1 온보딩 (첫 방문 1회)

**입력:**
- 생년월일 (필수)
- 출생 시간 (선택 — "모름" 시 시주 제외, 3주로 계산)
- 성별 (대운 순행/역행 판별용)

**결과: 투자 체질 프로필**
- 일주 한자 + 한글 (예: 庚金 경금)
- 사주 원국 4주 시각화 (천간·지지 + 오행 색상)
- 오행 분포 차트
- **투자 체질 분류** (사주 기반): 공격형 / 안정형 / 직감형 / 분석형 등
- 투자 체질 해설 (예: "경금 일주 — 원칙에 강한 가치투자형. 손절이 늦는 경향.")
- 카카오톡 공유 버튼 → **투자 체질 카드** 이미지 공유

**데이터 저장:** localStorage (가입 없이). 서버 전송 없음.

### 3.2 메인 피드 (매일 열리는 화면)

피드형 스크롤 (위 → 아래):

**상단: 오늘의 매매 기운**
- 점수 3종: 판단운 / 실행운 / 인내운 (각 0~100)
- 한줄 코칭 (예: "오늘 편관의 기운 — 과감한 결단은 좋으나 무리한 레버리지는 흉")

**중단: 명리 해설**
- 오늘 일진(日辰)과 내 명식의 관계를 투자 맥락으로 풀이
- 십신 해석 (예: "정재의 날 — 꾸준한 적립이 길한 날")
- 신살 판별 결과 반영
- 오늘의 조언 1~2문장

**하단: 월간 시그널 카드** (2단계)
- "5월 리밸런싱 결과 보기 →" 카드 1장
- 탭하면 시그널 탭으로 이동

### 3.3 내 투자 사주 (프로필 탭)

- 사주 원국 4주 시각화
- 오행 분포 차트
- **투자 성향 상세 분석:**
  - 리스크 성향 (오행 균형 기반)
  - 의사결정 스타일 (십신 분포 기반)
  - 강한 시장 / 약한 시장 (오행 상생상극 기반)
- 올해 세운 해설 → **올해 투자 흐름**
- 현재 대운 해설 → **장기 투자 국면**
- 카카오톡 공유 버튼

### 3.4 투자 시그널 (시그널 탭, 2단계)

- 자산군 선택: 한국주식 / 미국주식 / 코인
- 월간 리밸런싱 시그널 (BUY / HOLD / SELL / WATCH / KILL)
- 종목별 퀀트 점수 (기술적 + 매크로 + 펀더멘털 or 온체인)
- **"순수 퀀트 기반 분석"** 명시 (사주 무관)
- 기존 `signal/engine.py` 출력을 프론트에 연결

## 4. 운세 콘텐츠 생성 로직

### 기존 인프라 활용

| 기존 모듈 | 활용 |
|---|---|
| `manseryeok/core.py` | 유저 생년월일 → 명식 4주 계산 |
| `saju/relations.py` | 일진 × 명식 천간합/충, 지지 관계 |
| `saju/tengod.py` | 십신 계산 → 투자 맥락 해석의 핵심 |
| `saju/shinsal.py` | 길신/흉신 → 코칭 메시지 보정 |
| `saju/daeun.py` | 대운 → 장기 투자 국면 |
| `saju/sewoon.py` | 세운 → 올해 투자 흐름 |
| `saju/scorer.py` | 종합 점수 → 매매 기운 점수로 재해석 |

### 신규 개발 필요

**투자 체질 분류기 (`saju/investor_profile.py`)**
- 명식의 오행 분포 + 십신 분포 → 투자 체질 유형 매핑
- 분류 기준:
  - 비겁(비견/겁재) 강 → **독립형** (자기 판단 고집, 역추세 매매)
  - 식상(식신/상관) 강 → **직감형** (창의적 종목 발굴, 테마주)
  - 재성(편재/정재) 강 → **실리형** (수익률 중시, 배당/가치)
  - 관성(편관/정관) 강 → **원칙형** (룰 기반, 시스템 매매)
  - 인성(편인/정인) 강 → **분석형** (리서치 중심, 신중)
- 오행 균형도에 따라 리스크 성향 보정 (편중 → 공격적, 균형 → 안정적)
- 유형별 해설 텍스트 템플릿

**일일 투자 운세 생성기 (`saju/daily_fortune.py`)**
- 일진 × 명식 관계 → 판단운/실행운/인내운 점수
- 십신 + 관계 조합별 투자 코칭 메시지 템플릿
- 카테고리 매핑: 편재/정재 → 매매운, 정관/편관 → 판단운, 인성 → 인내운

**해설 텍스트 템플릿 (`data/fortune_templates/`)**
- 십신 10종 × 관계 유형별 투자 맥락 해설
- 신살별 보정 메시지
- 세운/대운 해설 템플릿

## 5. 기술 아키텍처

### 스택

| 레이어 | 기술 | 비고 |
|---|---|---|
| 프론트엔드 | Next.js (React, SSR) | PWA 준비, og:image SSR |
| 백엔드 | FastAPI (기존 확장) | 운세 API 엔드포인트 추가 |
| 사주 엔진 | 기존 `saju/*`, `manseryeok/*` | 그대로 활용 |
| 퀀트 엔진 | 기존 `quant/*`, `signal/*` | 2단계에서 프론트 연결 |
| 유저 데이터 | localStorage (1단계) | 서버 DB 없이 시작 |
| 배포 | Railway | 현행 유지 |

### 시스템 구성

```
[Next.js SSR]  ←→  [FastAPI]  ←→  [사주 엔진 (기존)]
     │                 │               [퀀트 엔진 (기존)]
     │                 │
 og:image 생성     운세/프로필 API
 카카오 SDK        시그널 API (2단계)
```

### 신규 API 엔드포인트 (1단계)

| 엔드포인트 | 메서드 | 역할 |
|---|---|---|
| `/api/saju/profile` | POST | 생년월일시 → 명식 + 투자 체질 프로필 |
| `/api/saju/daily` | GET | 오늘의 매매 기운 (판단/실행/인내 + 해설) |
| `/api/saju/yearly` | GET | 올해 세운/대운 투자 흐름 해설 |
| `/api/card/{encoded_id}` | GET | 공유용 투자 체질 카드 (og:image) |

기존 API (`/health`, `/signals/*`)는 유지. 2단계에서 프론트 연결.

## 6. 카카오톡 공유 (바이럴)

### 공유 카드 구성
- **투자 체질 카드 이미지**: 일주 + 오행 분포 + 체질 유형 + 한줄 해설
- og:title: "나는 경금 일주 — 가치투자형"
- og:description: "사주캔들에서 내 투자 체질을 알아보세요"
- og:image: 서버사이드 렌더링된 카드 이미지

### 바이럴 루프
```
A가 투자 체질 카드 공유 (카카오톡)
  → B가 링크 클릭
  → 카드 랜딩 페이지 (A의 결과 + "나도 해보기" CTA)
  → B 생년월일 입력
  → B의 투자 체질 카드 생성
  → B도 공유...
```

### URL 구조
- `sajucandle.com/card/{encoded_id}` — 공유 랜딩 (결과 + CTA)
- `sajucandle.com/` — 메인 (온보딩 or 피드)
- `sajucandle.com/feed` — 매일 운세 피드
- `sajucandle.com/profile` — 내 투자 사주

## 7. 런칭 단계

### 1단계: MVP — 투자 특화 사주 콘텐츠

**범위:**
- 온보딩 (생년월일 → 투자 체질 프로필)
- 메인 피드 (매일 매매 기운 + 명리 해설)
- 내 투자 사주 (프로필 탭)
- 카카오톡 공유 (투자 체질 카드)

**목표:** DAU 확인, 리텐션율 측정.

**의식적으로 뺀 것:**
- 투자 시그널 탭 (2단계)
- 한국 주식 유니버스 구축 (2단계)
- 유저 DB / 회원가입 (필요 시점에 도입)
- 궁합 / D-Day / 랭킹 (유저 반응 보고 판단)
- 수익화 (유저 확보 후)

### 2단계: 퀀트 시그널 합류

**범위:**
- 투자 시그널 탭 추가
- 한국 주식 유니버스 구축 (코스피 대형주 30개)
- 자산군 선택 (한국주식 / 미국주식 / 코인)
- 기존 `signal/engine.py` → 프론트엔드 연결

### 3단계: 수익화 & 확장

**범위:**
- 유료 구독 모델 도입
- 푸시 알림 (매일 아침 운세)
- 네이티브 앱 전환 검토

## 8. 제약사항 & 리스크

### 기술 제약
- yfinance 1h 인터벌 60일 제한 (일봉은 무제한).
- 한국 주식 가격 데이터는 yfinance로 KRX 종목 조회 가능하나, 상장일/설립일 데이터는 별도 수집 필요.
- 카카오 SDK 연동에 카카오 개발자 앱 등록 필요.

### 콘텐츠 리스크
- 투자 코칭 메시지가 "투자 조언"으로 해석될 수 있음 → **면책 문구 필수** ("본 콘텐츠는 오락 목적이며 투자 조언이 아닙니다").
- 운세 텍스트 품질이 앱 전체 경험을 좌우함 → 템플릿 퀄리티가 핵심.

### 비즈니스 리스크
- "투자하는 사주 팬" 니치가 충분한 시장 규모인지 불확실.
- 무료로 시작 → 수익화 전환 시 유저 이탈 가능성.

## 9. 성공 지표 (1단계)

| 지표 | 목표 |

| 카드 공유 → 신규 유저 전환율 | 20%+ |

| DAU (일일 활성 유저) | 런칭 1개월 후 측정 |
| 피드 평균 체류시간 | 2분+ |
